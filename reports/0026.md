# BUG-26 — GoodMorning intro 的 next 指向已退場的 tavern_catchup.py

> `doc` / `wrong` / `duplicate`　回報者：basecamp

## 描述

GoodMorning step=intro 的回傳檔 `## next` 第 1 項指路到 `python AgentCommands/Tools/tavern_catchup.py --persona <p> --quiet-system`，
而該工具 2026-08-20 已退場（自己印退場公告、exit != 0）。正確入口是
`run_cmd.py --persona <p> run Tavern --arg op=catchup`（實作 UCL_TavernCatchupService / Cmd_Tavern.Op_Catchup）。

⚠ 這一族的形狀：**指路牌比實作舊**。它不會報錯到讓人放棄 —— 退場公告很友善、有指新路，
所以照做的人只是多付一次來回；但如果哪天退場公告被拿掉（純 file-not-found），
照 next 走的人會得到一個跟「catchup 壞了」同形的失敗。

同族還要一起掃：任何 C# 端組 `## next` 字串時寫死 `tavern_catchup.py` 的地方（不只 GoodMorning intro，
Ding / 其他儀式的 next 也可能有同一行）。修法建議：next 裡的 catchup 指令由單一常數/組裝函式產出，
不要各步各寫一份字串 —— 兩份會漂，而漂掉的那一份沉默。
