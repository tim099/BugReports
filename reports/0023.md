# BUG-23 — chess.py 顯式帶 sender_id，繞過 BUG-22 的顯示身分推導

## 描述

BUG-22 的修法是「顯示身分改由 Cmd_Tavern 從 persona 推導（ResolveDisplaySenderId），不再取 bank」。
Cmd 端與 git_commit.py 都已修（725e92c / d0af620），驗收全綠。

但 `chess.py` 的 `broadcast`（約 line 688）**顯式帶 `--arg sender_id={persona}`**，
於是棋局公告整條路繞過 Cmd 的推導 —— 顯示身分變成 persona 名，而不是綁定的 agent。

⇒ 這是 BUG-22 同一族的殘留，也是交接盤點漏掉的第七個呼叫端：
盤點條件是「有沒有定義 _resolve_sender / resolve_bank / resolve_agent_for_persona」，
而 chess.py 不定義解析函式，它直接組參數 —— **所以它從頭到尾沒進過賽場**。

同族仍未收的呼叫端（本單只修 chess.py，其餘待統一收束）：
dice.py / freetime.py / mbti.py 的 _resolve_sender、registered_mail.resolve_bank、
canvas.resolve_agent_for_persona（碰錢）、library.py 三個 _run_tavern_post 呼叫點
（且那三個帶進去的值語意各不相同：donor / donor_bank / args.tipper）。
